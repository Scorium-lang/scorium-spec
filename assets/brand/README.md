# Scorium brand assets

This repository uses the **Language specification (no implementation badge)** logo.

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-light.svg` | Logo with wordmark, for README and documentation headers. |
| `mark.svg`, `mark-light.svg` | Full logo tile, for avatars and larger standalone marks. |
| `icon.svg`, `icon-light.svg` | Simplified logo tile, for small icons and favicons. |

The `-light` files are for light backgrounds; the other files are for dark
backgrounds. The README selects its variant using the reader's color scheme.
